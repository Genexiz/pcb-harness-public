# Subscription-first Local MCP Implementation Plan

> Execute inline using superpowers:executing-plans. User approved the updated written spec and requested continuation. Preserve the existing development branch; one fresh whole-change review at the end.

**Goal:** working local STDIO MCP tools around the existing Kernel, without model API keys, with deterministic demo/protocol tests and explicit native readiness limits.

**Architecture:** A serialized service owns one configured backend/Kernel and one persistent run directory. The MCP SDK handles transport/schema negotiation; thin tools expose status/connect/query/execute/checkpoints/verification. Inference and sign-in stay in the host.

**Tech stack:** Python 3.11, official `mcp==2.3.0`, existing kicad-python 0.8.0, pytest; no provider SDK, HTTP listener or cloud deployment.

**Spec:** ../../PCB Harness — Design Spec (v2).md, sections 6–7/10/12 updated 2026-10-09.

## Global constraints and rulings

- No model API key, no subscription credential access, no sampling/inference from the server.
- STDIO only; stdout is protocol traffic, logs go to stderr.
- The native backend never silently falls back to Memory. Memory is explicit `--backend memory`, test-only and never edits KiCad.
- Native edits remain disabled while current M1 native acceptance is pending. Prepare protocol/native read queries now; this does not mark M1 or M2 routing proof complete.
- Fixed project/workspace/run paths come from trusted launch arguments, not model tool arguments. Native scratch-only restrictions stay in the adapter. Run directory is persistent across reconnects; no tool can reset recovery or choose a fresh journal to bypass it.
- All calls share a service lock; disconnect cannot race an active mutation. A fixed run lease prevents two servers writing one journal.
- Reuse expected_revision, unique action IDs, strict/permissive semantics, locks, rollback and structured errors from Kernel.
- Retain current native GUI blocker; no request for provider key and no claim that a host is connected from config alone.

## Review focus

- Reconnect/restart must not erase an uncertain journal or turn historical replay into current success.
- Default native transport failures must not select a demo backend or expose enabled mutations.
- Invalid project/run paths or unknown arguments must fail before external writes.
- Tool annotations/errors must distinguish read queries from mutation and failure from success.
- STDIO framing, legacy protocol negotiation and process cleanup must work with the actual SDK/client, not a mocked server.
